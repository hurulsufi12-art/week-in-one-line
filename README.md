Entry for [Your Week in One Line](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced)
on make.fun: one line, at most 100 characters, summing up the entrant's
week — the win, the fail, the chaos.

## Run

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` (UTF-8, no trailing
newline, 93 characters).
